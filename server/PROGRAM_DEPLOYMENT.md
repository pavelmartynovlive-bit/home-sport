# Обновление программы: удаление подъёмов на носки

Сначала обновить API на существующей VPS, затем публиковать клиент. Старый API
принимает только 30 упражнений; новая программа отправляет 29. Новый API принимает
оба формата, сохраняя старую историю без изменений.

Задание для локального Codex на Mac:

> В репозитории home-sport возьми ветку remove-calf-raises. Используй существующий
> SSH-доступ к VPS home-sport.132-243-23-229.sslip.io. Не выводи ключи и закрытые
> файлы подключения. Обнови только API с помощью server/upgrade-drafts.sh из этой
> ветки (запускается sudo на VPS). Скрипт сохраняет снимок БД и старый код,
> сохраняет конфигурацию, ключ, nginx и расписания копий. Проверь HTTPS /health:
> exerciseCounts должен содержать 29 и 30, ok и draft — true. Проверь авторизованный
> GET истории и черновика без изменения пользовательских данных. После успешной
> проверки слей PR этой ветки в main и проверь GitHub Pages. Не удаляй историю,
> черновик, локальные данные или резервные копии.

Для проверки без ключа:

```sh
curl -fsS https://home-sport.132-243-23-229.sslip.io/health
```
