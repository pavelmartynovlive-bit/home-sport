# Иллюстрации техники

30 локальных изображений WebP, по одному на каждое упражнение из `src/program.ts`.
Сгенерированы по визуальному образцу пользователя: анатомические серые фигуры на белом фоне, работающие мышцы выделены красным, показаны положения упражнения.

Файл `<exercise-id>.webp` открывается в существующем блоке техники вместе с текстовыми подсказками. Все изображения входят в офлайн-кэш PWA. Для GIF или MP4 можно изменить `techniqueMedia`, оставляя файл меньше 2 MiB.

`shrugs.webp` нет: шраги удалены из текущей программы, вместо них используется `floor-press.webp`. Исторические записи сохраняются отдельно в данных тренировок.
